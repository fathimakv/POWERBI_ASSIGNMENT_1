# POWERBI_ASSIGNMENT_1
Data Transformation and Data Modeling
Project Overview:
This project is an assignment completed using PowerBi.It focuses on data transformation and data modeling using the provided Excel datasets.
Files Used:
List of orders.xlsv,
Orders details.xlsv,
Sales target.xlsv.
Tools used:
Microsoft PowerBi,
Power Query.
Work Completed:
Imported data from Excel files into PowerBi.Performed data cleaning and transformation using Power Query.Prepared and organized datasets.Performed data modeling in PowerBi.
Objective:
The main objective of this assignment was to gain practical knowledge of data transformation and data modeling in PowerBi.
